## 🚀 Running the Code

Make sure Node.js is installed on your machine.

Clone the repository:

```bash
git clone https://github.com/sfqhamirah/js-algorithm.git
```

Navigate to the repository:

```bash
cd js-algorithm
```

Run any JavaScript file using Node.js:

```bash
node lab4-linear-search.js
```

Replace the filename with the algorithm you want to run.
